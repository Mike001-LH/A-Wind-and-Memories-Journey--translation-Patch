# The Journey of Wind and Memory – Translation Patch

English 🇬🇧 and Japanese 🇯🇵 translation patches for
**The Journey of Wind and Memory Demo v0.49**.

Made with permission from the original developer.

## Available Languages

- 🇬🇧 English
- 🇯🇵 Japanese

## Installation

1. Download the patch for your preferred language from the latest release.
2. Extract the archive.
3. Copy the files into the game folder and replace the original files.
